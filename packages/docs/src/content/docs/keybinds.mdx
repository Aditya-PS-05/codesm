## Messages and transcript

| Key | Action |
|-----|--------|
| `Enter` | Send a message; queue it if work is active |
| `Tab` | Queue a message while busy; toggle Smart/Rush mode while idle |
| `Ctrl+T` | Expand or collapse tool output, reasoning summaries, and specialist details |
| `Ctrl+P` | Open the command palette |
| `Ctrl+L` | Clear the displayed transcript |

Drag over transcript text to select it, then press **Ctrl+C** to copy the selection.
**Esc** clears the selection. Selecting text across a link or tool output does not
open the link or collapse the output.

When a tool group or specialist is focused, **Enter** or **Space** toggles its
details. **C**, **Y**, or **Ctrl+Shift+C** copies selected text, or the full focused
message and tool output when nothing is selected. Some terminals reserve
**Ctrl+Shift+C** for their own selection; **Ctrl+C** copies codesm's selection.

## Sessions and control

| Key | Action |
|-----|--------|
| `Esc` | Clear selected text; otherwise interrupt active work |
| `Ctrl+C` | Copy selected text; otherwise interrupt active work or quit when idle |
| `Ctrl+Z` | Interrupt active work; quit when idle |
| `Ctrl+N` | Start a new session when idle |

Use the arrow keys and **Enter** to choose items in pickers; **Esc** closes dialogs.
When command or file suggestions are open, their selection controls take priority.

## Models, modes, and themes

Use slash commands for these settings:

| Command | Action |
|---------|--------|
| `/models` | Select a model |
| `/mode` | Choose Smart or Rush mode |
| `/smart`, `/rush` | Set a mode directly |
| `/theme` | Choose a color palette; Terminal is the default |
| `/connect` | Connect a provider |
| `/session` | Browse saved sessions |
| `/cost` | Inspect usage and cost |

The terminal uses the shortcuts above directly. It does not load a `Ctrl+X`
leader, Vim mappings, or custom `keybinds` from `codesm.json`.
