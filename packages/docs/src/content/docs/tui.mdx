---

Start the interactive terminal interface in the current directory:

```bash
codesm run
```

Or select a project:

```bash
codesm run /path/to/project
```

## Transcript

The conversation fills the terminal without a sidebar. Messages and tool activity
appear in order, with the prompt fixed at the bottom. Tool output stays collapsed
by default. Press **Ctrl+T** to expand or collapse full output, diffs, reasoning
summaries, and specialist details.

Scroll up to read earlier output. New activity follows the conversation only when
you are already at the bottom.

Drag over a message or tool output to select text, then press **Ctrl+C** to copy
it. **Esc** clears the selection. Copying a selection keeps active work running.
Hovering text shows a copy hint in the footer. Terminals that support mouse pointer
shapes also show an I-beam; GNOME Terminal keeps its own pointer shape.

## File references

Type `@` to open the file picker and insert a path into your prompt:

```txt frame="none"
How is auth handled in @src/auth/index.ts?
```

You can also include file paths directly, including paths to images you want the
agent to inspect.

## Running commands

Ask the agent to run a command as part of your task:

```txt frame="none"
Run the tests and investigate any failures.
```

Shell calls and their results appear in the transcript and follow the configured
approval rules. Use **Ctrl+T** to inspect the complete output.

## Slash commands

Type `/` to open command suggestions, or use **Ctrl+P** for the command palette.

| Command | Description |
|---------|-------------|
| `/help` | Show available commands |
| `/new` | Start a new session |
| `/session` | Browse saved sessions |
| `/connect` | Connect a provider |
| `/models` | Select a model |
| `/mode` | Select Smart or Rush mode |
| `/smart`, `/rush` | Set the mode directly |
| `/theme` | Choose a color palette |
| `/cost` | Inspect session usage and cost |
| `/status` | Show the current mode, model, and directory |
| `/debug <problem>` | Start the verified debugging workflow |
| `/init` | Generate project instructions |
| `/fork` | Fork the current session |
| `/branches` | Show session branches |
| `/audit` | Show the audit log |

**Terminal** is the default color palette. Theme selection uses `/theme`;
**Ctrl+T** controls transcript details.

## Modes

**Smart** uses your selected model. **Rush** uses the current provider's configured
fast-model choice when one is available. The footer shows the effective model.
Use `/mode`, `/smart`, or `/rush`, or press **Tab** while idle.

These are model choices. Read-only planning is available through the planner
specialist and `read_only` configuration. See [Agent Modes](/modes) and
[Agents](/agents).

## Input and queued messages

Type a message and press **Enter** to send it. During active work, **Enter** or
**Tab** queues the message for the next turn. The current task finishes before the
queued message runs. **Esc** clears selected text first; otherwise it interrupts
active work and its workers.

The composer is a single-line input. Use ordinary text and file references to
provide longer instructions; there is no external-editor shortcut.

## Usage display

The footer shows the current mode/model and an estimate of context remaining.
Use `/cost` for token counts, request counts, estimated usage, and session cost.
Costs remain unknown for requests without configured pricing.

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Enter` | Send a message, or queue it during active work |
| `Tab` | Queue a message while busy; toggle Smart/Rush mode while idle |
| `Ctrl+T` | Expand or collapse transcript details |
| `Esc` | Clear selected text; otherwise interrupt active work |
| `Ctrl+C` | Copy selected text; otherwise interrupt active work or quit when idle |
| `Ctrl+Z` | Interrupt active work; quit when idle |
| `Ctrl+P` | Open the command palette |
| `Ctrl+N` | Start a new session when idle |
| `Ctrl+L` | Clear the displayed transcript |

See [Keybinds](/keybinds) for message-copy and dialog controls.
