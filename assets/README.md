# Codesm media

`logo.svg` and `logo-dark.svg` are the custom Codesm mark and wordmark for light
and dark backgrounds. Both use vector paths and require no installed fonts.

## Astra demo

[`codesm-astra-demo.mp4`](codesm-astra-demo.mp4) is the final **56.6-second** edit
at 1920×1080, 30 fps, encoded as H.264. The first second of the original export
has been removed. `codesm-astra-demo.jpg` is a clickable preview made from an
actual frame of the video.

The footage shows a real native Codesm session using GPT-6 Astra to build Lunar
Courier, a playable browser game with original Canvas assets. Build excerpts
are labeled at 4× speed; gameplay runs at normal speed. The Mac window framing
was added during editing; the capture itself ran on Linux.

Four model requests produced the game files. A token budget guard stopped the
run before the model's own verification. JavaScript syntax and nine browser
checks were verified locally afterward. Two small presentation edits adjusted
the footer spacing and removed a decorative registration symbol; the game
logic was unchanged. The video omits waiting periods and the budget error.
